# 端到端时延证据 —— 控制路径 ≈34ms (2026-09-24 真机实测)

> 本文为仓库内证据留档（来源: Pi 5B 真机, Ubuntu 24.04 + Jazzy + Astra Pro,
> `depth_source:=topic` 订阅 /camera/depth/image_raw）。引用该数字时请标注
> "2026-09-24 真机 v2.9.11 实测"。

## 分段 (控制路径, 不过网络)

| 段 | 耗时 |
|---|---|
| 相机 → 节点 (DDS 订阅) | ≈9 ms |
| 节点处理 (解码+注入+感知小计) | ≈17.9 ms |
| 节点 → 消费者 (DDS 发布) | ≈7 ms |
| **合计** | **≈34 ms** |

决策周期 100 ms ⇒ 最坏情形端到端 ≈134 ms（仍满足"传输无延迟"要求）。

## 节点内 per-frame 分解 (v2.9.11, 真机日志"感知:"行)

- 主线程: 解码 ≈2.0~2.9 ms; 驱动注入 ≈8.0~10.3 ms
- 感知: 深度门槛 ≈0.2~0.6 ms; 反投影 ≈2.1~3.2 ms; 到 base ≈1.7~3.6 ms;
  地面分割 ≈11.1~15.8 ms; 高度图 ≈0.8~1.0 ms (感知小计 ≈17~21 ms)
- 其余 ≈2.4~2.9 ms; **总计 ≈20~24 ms/帧; CPU 占空 ≈47%**

## 备注

- 该测量早于 v2.9.16 (`cell_skip_ransac`)；v2.9.16 后分割路径构成变化（cell 成功时
  跳过 RANSAC），34ms 总量按"同一帧回放"工装（`tools/pi_replay.py`）复测仍然成立。
- 上位机路径 `/safety/terrain_grid` = 4848 B/帧 ≈ 0.388 Mbit/s（同机本地直连达标）；
  远程 WiFi 链路实测吞吐仅 ~1.25 Mbit/s ⇒ 远程访问必须走紧凑话题（详见 README 横幅）。
- 测量方式: v2.9.11 真机分段计时（现场会话留档, 计时脚本 `pi_timing_v2911.sh`）。
