## 0 一句话

**要证明的事**：存在一类障碍物（镜面 / 透明），**超声（声波）看得见、深度相机（结构光/红外）看不见**；
这种"跨层不一致"就是 A 批检测器的签名，本实验要把签名**逐材质标定出来**（哪种材质成立、哪种不成立、边界在哪）。

## 2 前置条件（缺一项就别开跑）

### 2.1 硬件
- [ ] 本体（或相机 + 超声台架）就位，**静止**、地面平整；相机**俯视**到开阔地面（节点日志需有地面平面）
- [ ] 材质样本（建议最小集）：**镜面亚克力板**（已有 60×16cm）、**透明亚克力板/玻璃**、**纸板**（对照：两层都该看见）、

## 3 实验矩阵（最小集 5 材质 × 3 距离 = 15 测点；时间够再上"重复 3 轮"）

| # | 材质 | 代号 | 标称距离 | 期望：超声 | 期望：深度 2.5D | 期望：交叉层 |
|---|---|---|---|---|---|---|
| M1 | 镜面亚克力板（60×16cm） | `acrylic_mirror` | 1.0 / 1.8 / 2.6 m | 有回波（≈标称） | **零禁行格**（看穿） | **触发（核心签名）** |
| M2 | 透明亚克力板/玻璃 | `acrylic_clear` | 同上 | 有回波 | 零禁行格（穿透） | **触发** |
| M3 | 纸板（不透明漫反射） | `cardboard` | 同上 | 有回波 | **有禁行格** | 不触发 |
| M4 | 黑色绒布/海绵（吸声） | `black_cloth` | 同上 | 回波弱/无 | 零禁行格 | 不触发（超声也没回波） |
| M5 | 空白（无板） | `none` | 同上 | 无回波 | 全 Traversable/Unknown | 不触发（**假阳性对照**） |

- **高度**：板统一抬到 ≈0.35 m（`height_m=0.35`）；若超声瞄不到板，再补一组 0.15 m（记进 `note`）
- **角度**：板面**正对**狗（`angle_deg=0`）；另补 1 组 **±30° 斜置**（只作边界记录，不进主矩阵）
- **顺序**：**打乱**（不要材质顺序固定，避免温度漂移/相机曝光变化与材质混淆）。建议按轮次随机：
  `M3 M5 M1 M4 M2 / M2 M1 M5 M3 M4 / M5 M4 M2 M1 M3`（每轮 15 测点整体换一次顺序）
- **重复**：同一测点**连续采 10 s**（≈20 条采样）—— 逐点 ≥3 条有效才算数（抗单帧抖动）

## 4 现场步骤（每个测点 5 步，约 40 s）

1. **摆**：板摆到标称距离（卷尺量**板面→相机中心**水平距离），抬到 0.35 m，板面朝狗；人退到狗侧后方（别挡超声/相机）
2. **标**：改 `~/label.json` 写清本测点（**脚本每轮重读，不用重启**）：
   ```json
   {"material": "acrylic_mirror", "material_cn": "亚克力镜面板",
    "dist_m": 1.00, "height_m": 0.35, "angle_deg": 0, "note": "迎光面朝狗"}
   ```
3. **采**：起采集（同一份 JSONL 持续追加；`--symbols` 到点数自动退出）：
   ```bash
   python3 ~/hidden_probe.py --label ~/label.json --out ~/a_mat_$(date +%m%d).jsonl \
           --terrain --secs 10 --hz 2
   ```
   采集过程中看一眼每行的摘要：`HIDDEN=Y/n · 超声 center=x.xx m/ok · 带内禁行格=n/m` —— 这就是现场判据
4. **记**：换材质前**拍照**（板 + 卷尺读数同框）+ 在 `~/notes.md` 记一行（材质/距离/异常现象）
5. **复核**：一趟跑完（15 测点）后立刻出矩阵，看有没有 `?` 或明显异常，再决定要不要补测
   ```bash
   python3 ~/hidden_summarize.py --in ~/a_mat_1015.jsonl --out ~/矩阵_1015.md
   ```

> **回归点（KB 留的）**：顺手核验**方向标签 ↔ 扇区**是否按 `+y=左` 口径 —— 把板只放在**狗左前方 30°**，
> 看节点 `hidden_dir` 应为 `left`（若为 `right` 就是方向符号反了，是**要报的缺陷**）。

## 6 验收判据（跑完拿这张表判"过/不过"）

| 判据 | 期望 | 不过怎么办 |
|---|---|---|
| **核心签名**：镜面 / 透明板 ⇒ 节点 `hidden_obstacle=true` | ≥80% 采样点（每测点 ≥3 条有效） | 查 §7 坑表（多为地形未注入 / 板贴地 / 距离出窗） |
| **对照①**：纸板 ⇒ **不**触发（深度应看见禁行格） | 触发率 ≈0 | 若触发 ⇒ 纸板位置/高度让 2.5D 看不到（记录并复核，不是缺陷就是摆位问题） |
| **对照②**：空白场景 ⇒ **不**触发 | 0 次 | 有触发 ⇒ 检查超声是否有假回波（迟滞/串扰），**报缺陷** |
| **吸声**：绒布 ⇒ 超声也无回波 | 超声 valid 低 | 若超声仍有回波 ⇒ 记录（材质并不吸声/距离太近） |
| **方向口径**：左侧板 ⇒ `hidden_dir=left` | 一致 | 不一致 ⇒ **符号反了，报缺陷**（KB 明确留的核验点） |
| **距离一致**：`hidden_dist_m` ≈ 卷尺距离 | ±0.25 m 内 | 差得多 ⇒ 查超声标定/安装角 |
| 证据完整 | JSONL + 矩阵 + 节点日志 + 照片 + `md5sum` 清单 | — |

## 7 已知坑（每条都是踩过的）

| 坑 | 现象 | 处置 |
|---|---|---|
| **`ROS_DOMAIN_ID` 没设** | `ros2 topic list` 只有 `/parameter_events`、`/rosout`，以为节点没跑 | 一律 `export ROS_DOMAIN_ID=42`（Pi 上节点在这个 domain；本会话实测踩过） |
| **回放/深度缺 `camera_info`** | 节点落 FOV 兜底内参 ⇒ 平面拟合与工装不对齐（R-8 那个坑） | 真机跑相机节点不受影响；若用回放灌帧，**必须**发 `image_raw` + `camera_info`（`pi_replay.py` 自带） |
| **深度无数据**（本轮现状） | `/camera/depth/image_raw` 无发布；节点 `degraded=true`、地形全 Unknown ⇒ 交叉层恒不触发 | 查相机 USB 供电/线（Pi5 的 USB 预算），必要时换线/换口，重启 `astra_camera` |
| **超声链路未上** | `/ultrasonic` 话题不存在 | 四路走 STM32 0x02 上报（待师兄固件）；**单颗 GPIO 真读已跑通**（2026-10-04）⇒ 可先用单颗做 M1 核心签名，三方向/底部标 `NA` |
| **板贴地** | 2.5D 把板当"地面延续" ⇒ 禁行格 0（看起来"隐身"但其实是几何） | 板必须抬到 ≈0.35 m（离地），并在 label 写 `height_m` |
| **距离出窗** | <0.90 m 或 >3.00 m 一律不判（近场由 L0 超声盲区补偿覆盖） | 主矩阵用 1.0/1.8/2.6 m；贴脸段单独记录但**不算隐身判据** |
| **地形未注入** | 节点日志 `NO PLANE` / `DEPTH GATE` ⇒ `clear_local_terrain()` ⇒ 交叉层恒不触发 | 让相机俯视开阔地面，直到日志出现平面（`平面valid=1`） |
| **节点没在跑 / 采集时节点重启** | JSONL 里 `age_s.fusion` 很大 | 采集前 `--preflight`；中途重启就重开一个 JSONL |
| **`ros2 topic echo /ultrasonic` 报类型无效** | `The message type ... is invalid`（daemon 在不同 domain 上） | 用 `--no-daemon` 或直接跑 `hidden_probe.py`（本脚本自己 import 消息类型，不依赖 daemon） |
| 人站太近挡住声锥/视场 | 读数跳 | 采样时人退到侧后方 ≥1.5 m |
